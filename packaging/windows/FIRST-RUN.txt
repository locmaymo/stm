SillyTavern Manager for Windows
===============================

Running it
----------

Double-click SillyTavernManager.exe (or use the Desktop / Start Menu shortcut
if you installed with the Setup installer).

The SillyTavern Manager desktop window opens and starts the manager in the
background — no terminal window needs to stay open. The first run installs
SillyTavern itself, which takes a few minutes on a slow disk; the Overview page
shows the progress.

You can also open the console in your own browser at any time from the system
tray icon ("Open in Browser") or at:

    http://127.0.0.1:7860

System tray & closing the window
--------------------------------

Clicking the close (X) button hides the window to the Windows system tray
(bottom-right corner of the taskbar) so SillyTavern and your Cloudflare tunnel
keep running in the background.

Right-click the SillyTavern Manager icon in the system tray to:

    - Open SillyTavern Manager
    - Open SillyTavern
    - Open in Browser
    - Start with Windows
    - Restart Manager
    - Quit SillyTavern Manager (stops SillyTavern and the tunnel cleanly)

Where your data lives
---------------------

    %LOCALAPPDATA%\SillyTavernManager

Characters, chats, profiles, backups, logs and settings are all kept there,
outside the program folder. Updating or reinstalling the app leaves your data
untouched.
