# Termux

Install Node.js in Termux, clone this repository, run `npm ci`, then start it with `npm start`. The manager automatically detects Termux and uses `$PREFIX/var/sillytavern-manager`; no launcher path is needed. It has no native Node module dependency. Cloudflared is optional; when unavailable the tunnel card reports the missing capability while local access continues to work. Nothing about it is installed by hand: Android starts position-independent executables only and Cloudflare's own Linux builds are not, so the manager first asks `pkg` for Termux's build of cloudflared, and if that is unavailable runs Cloudflare's build under `termux-chroot` from the `proot` package, installing it the same way. `STM_CLOUDFLARED_PATH` still wins over both. On a phone the tunnel also runs over HTTP/2 on IPv4, because mobile networks block QUIC often enough that the default never connects.
